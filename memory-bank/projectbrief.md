# WayStation Project Brief

## Overview
WayStation is a no-code, secure hub that empowers large language models (LLMs) to take real-world actions on behalf of information workers. It serves as middleware between LLMs and everyday business applications, making agentic AI capabilities accessible and practical.

## Core Requirements
- No-code, secure integration hub
- Support for multiple LLM providers (OpenAI, Anthropic, etc.)
- Enterprise-grade security and compliance features
- Seamless integration with common business tools:
  - Work Management (Monday, Jira)
  - Communication (Slack, Gmail)
  - Document Storage (Google Drive, Dropbox)
  - Enterprise Systems (Salesforce, Microsoft 365)
- Comprehensive logging and audit capabilities
- SSO integration support

## Goals
- Simplify AI-tool integration for non-technical users
- Provide enterprise-ready security and compliance
- Enable seamless LLM-powered workflow automation
- Maintain vendor neutrality
- Scale to serve enterprise customers globally

## Vision
Become the essential middleware layer between LLMs and applications, similar to how HuggingFace unified working with models and datasets.
